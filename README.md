# DriverBee

DriverBee is an on-demand driver booking platform for personal cars in Warangal, Telangana.

## Features
- **Hourly & Outstation Drivers**: Book professional, background-checked drivers for local city drives, round trips, or outstation travel.
- **Immediate or Scheduled Booking**: Get a driver in under 15 minutes or reserve in advance.
- **Admin Dashboard**: Real-time dispatch management, driver duty toggling, and live ride status tracking.
- **Family & Safety Focus**: Live GPS trip sharing and 24/7 SOS assistance.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide React Icons
- Supabase Integration

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
